================================================================
  校园网自动登录脚本 —— 使用说明
================================================================

【这是什么】

一个自动登录校园网的小工具。开机后、或者校园网掉线后，它会自己
帮你填学号密码、认验证码、点登录。

原理是用浏览器自动化（Selenium 驱动 Chrome/Edge），不是破解协议。
每隔几分钟就检查一次网络状态：有网就什么都不做，没网才动手。


【运行前需要什么】

1. Windows 系统
2. Python 3.10 或更高版本
   没装的话去 https://www.python.org/downloads/ 下载
   ★ 安装时务必勾选 "Add Python to PATH"
3. Chrome 或 Edge 浏览器（Windows 一般自带 Edge）


【安装步骤】

第 1 步  解压
    右键这个 zip → 全部解压缩，解到任意位置。

第 2 步  装依赖
    进入解压出来的 campus-net 文件夹，在文件夹窗口的「地址栏」
    输入 cmd 回车（会在该目录打开命令行），然后执行：

        pip install -r requirements.txt

    会联网下载 selenium、ddddocr 等几个包，等它跑完。

第 3 步  配置
    在同一个窗口里执行：

        copy config.example.json config.json
        notepad config.json

    记事本打开后，把这一行的学号改成你自己的：

        "username": "你的学号",

    如果用的是 Edge 而不是 Chrome，把

        "browser": "chrome",

    改成

        "browser": "edge",

    保存并关闭记事本。

第 4 步  存密码
    执行：

        python login.py --setup

    - 提示「学号/账号 [xxx]:」→ 直接回车
    - 提示「密码（输入时不显示）:」→ 输入密码
      ★ 屏幕上不会有任何字符显示，这是正常的，输完回车
    - 显示「密码已加密保存到 ...」就成功了

    密码用 Windows 自带的加密（DPAPI）保存，绑定你这台电脑的这个
    账户。别人拿到文件也解不开，也不会写进任何配置文件。

第 5 步  测试
    先断开校园网（注销，或等它自己掉线），然后双击：

        test-login.bat

    会弹出浏览器自动填表登录，整个过程 20-40 秒。
    窗口最后会显示结果。

第 6 步  设置开机自动运行
    执行：

        powershell -ExecutionPolicy Bypass -File install_task.ps1

    显示「已注册计划任务」就成功了。之后它会：

        - 你每次登录 Windows 时自动检查一次
        - 每隔 5 分钟检查一次
        - 有网：什么都不做，不弹窗、不打扰
        - 没网：自动启动浏览器登录


【日常使用】

装好之后基本不用管。

  想看它干了什么 ...... 打开 campus-net.log，最近的记录在最下面
  想手动跑一次 ........ 双击 test-login.bat
  想卸载 .............. powershell -ExecutionPolicy Bypass -File uninstall_task.ps1


【关于安全，你需要知道】

1. 脚本会替你在登录页上勾选「已阅读并同意《用户协议》《免责声明
   协议》《用户隐私协议》」。因为不勾的话登录按钮不生效。
   也就是说：这几个法律条款是由程序代表你接受的。

2. 你的密码不会出现在任何配置文件里，加密存在 secret.dat。

3. 如果 6 小时内连续失败 6 次，脚本会自己停下来不再尝试。这是为了
   防止你的账号被学校认证系统锁掉。手动登录成功一次后会自动恢复。

4. 每次尝试都会真的向学校服务器提交一次登录请求。所以改了密码
   记得重新跑一次第 4 步。


【出问题了怎么办】

问题：双击 test-login.bat，窗口里是乱码
    → 说明这个文件被记事本之类的编辑器保存过，编码坏了。
      重新解压一份即可。切记不要用记事本编辑 .bat 文件。

问题：浏览器弹出来，闪一下就没了
    → 这是失败的表现。看目录里的 failure-*.png（失败瞬间的屏幕
      截图）和 failure-*.html，以及 campus-net.log，基本能看出
      卡在哪一步。

问题：日志里说「等待页面稳定超时」
    → 学校登录页加载太慢。打开 config.json，把 probe_timeout 改大
      （比如 15）。

问题：找不到登录页上的输入框
    → 说明页面结构和预期不同。执行：

          python login.py --dump-form

      它会把页面上所有输入框、图片、按钮列出来。
      照着结果修改 config.json 里的 selectors。

问题：我不是四川工业科技学院的学生
    → config.json 里的 selectors 是针对该校门户量出来的，别的学校
      需要重新量（用上面的 --dump-form）。
      另外 portal 那一项也要改成自己学校的门户地址。

问题：账号被锁了
    → 先卸载计划任务（见上面「想卸载」），联系学校网管解锁，
      然后检查 config.json 里的学号是否正确、密码是否输错。


【技术细节（可选阅读）】

  语言        Python 3
  浏览器自动化 Selenium（Chrome / Edge）
  验证码识别   ddddocr，本地识别，不联网、不调用任何外部服务
  密码存储     Windows DPAPI（ctypes 直接调用，无第三方依赖）
  触发方式     Windows 计划任务（登录时 + 每 5 分钟 + 网络状态变化时）
               登录失败后会退避（默认 15 分钟不再重试），
               所以轮询虽快，登录尝试的密度仍被限住，不会把账号试锁
               不是常驻进程 —— 每次跑几秒就退出，崩了下一轮自动重来
  探测逻辑     请求外部地址判断外网是否通，被劫持才判定需要登录
  安全设计     重试上限 + 跨运行失败计数，避免把账号试错锁

本工具仅供个人在自己的账号、自己的设备上使用。
